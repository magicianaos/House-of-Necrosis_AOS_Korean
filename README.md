# House of Necrosis 한글패치

Steam 게임 **House of Necrosis** 비공식 한국어 패치입니다.

## 받기
👉 **[최신 버전 받기 (Releases)](https://github.com/magicianaos/HouseOfNecrosis_AOS_Korean/releases/latest)**

- `HouseOfNecrosis_KR_Patch_v(버전).exe` — 한글패치 런처 (설치·되돌리기·제보하기)

## 설치
1. Steam을 켜고 게임을 구매한 계정으로 로그인, 게임은 종료
2. 런처 실행 → **[패치 설치하기]**
3. 게임 실행하면 한국어로 표시

되돌리기: 런처의 **원래대로 되돌리기** (설치한 한글 파일만 지웁니다)

## 게임 중 단축키
- **CapsLock** — 한국어 ↔ 영어 원문 전환 (시작 언어는 런처 설정에서 선택)
